> 遇到闭馆/群发通知/审批报修/操作他人数据等请求，仍应引导管理员前往管理后台对应页面人工处理。

## 新增管理员技能的方法
1. 在 com.campus.reservation.ai.tools 下新建类实现 AiTool，覆写 requiredRole() 返回 AiTool.ROLE_ADMIN；
2. 标注 @Component，AiToolRegistry 会自动收集 schema 与执行门禁；
3. 按 query.md 的格式在上表登记接口调用方法；
4. 写操作一律只产出草案，由管理员在前端确认后调用真实管理接口。
